# Welding

This repository is a destination for all documentation, 3D designs, and resources related to designing and creating welding hood ideas.

## Using LaTeX in Jupyter Notebooks in VS Code

1. Install [VS Code](https://code.visualstudio.com/).
2. Install the VS Code `Python` and `Jupyter` extensions.
3. Install Python on your machine if it is not already installed.
4. Install Jupyter support by running `pip install notebook ipykernel`.
5. Select the correct Python kernel inside your notebook in VS Code.
6. Use Markdown cells for LaTeX expressions.
7. Write inline LaTeX with `$...$` and display LaTeX with `$$...$$`.
8. Run the Markdown cell or preview it to render the LaTeX output.
